# Examples: copyable starter files

Standalone files to copy into your own project. Each folder works on its own, with no dependency on the rest of this repository.

| Folder | What it is | Explained in |
|---|---|---|
| [`minimal/`](minimal/) | A complete checkpointing job in one short script (`train.py`), its `run.sh`, submit files for CHTC and the OSPool, and a container definition | [`recipes/00_minimal/README.md`](../recipes/00_minimal/README.md) |

These are copies of files in `recipes/`. Edit the recipe, then copy it here; don't edit the copies directly.
